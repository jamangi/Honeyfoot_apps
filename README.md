# Honeyfoot Apps

A React and Vite prototype for the Honeyfoot family of foot-care experiences.

## Game rules

- [Core mechanics](CORE_MECHANICS.md) defines the authoritative match flow, vocabulary, targeting, Condition stacks, Care Checks, hidden information, and reconstruction requirements.
- [Card reference](CARDS.md) documents every current card, its exact resolution and interactions, starter decks, and known differences between printed rules and the prototype engine.

## Start the local site

```powershell
npm.cmd run dev
```

Open <http://127.0.0.1:5173>. Press `Ctrl+C` in the terminal to stop the server.

## Create a production build

```powershell
npm.cmd run build
```
